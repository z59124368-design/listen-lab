# ListenSync · 听力歌词同步精听器

上传听力的 **MP3 音频** 与 **PDF 原文**，自动将音频时间轴与原文逐句对齐，实现像听歌看歌词一样的英语/多语言听力精听体验：

## 核心功能

- **自动时间轴对齐**：基于 `faster-whisper` 词级时间戳 + 半全局动态规划序列对齐 + 静音能量边界精修，自动跳过未写在原文里的考前引导语与停顿，将 PDF 原文逐句精准对齐到音频。
- **同步歌词播放**：播放时实时高亮并居中滚动当前朗读句子，支持双栏 PDF 提取、页眉页码清理与说话人标签识别。
- **点击任意句子跳转**：点击哪句话就立即从那句话开口处开始播放。
- **每一句单独听 / 跟读**：
  - **单句停顿模式**（或每句右侧 `▶ 单句`）：只播这一句，句末自动暂停，方便精听与听写；
  - **单句循环模式**（或每句右侧 `🔁 循环`）：无限单句循环，支持设置 `0s / 0.5s / 1.2s / 2.5s` 跟读间隔；
  - **连续歌词模式**：像音乐软件看歌词一样连续播放。
- **盲听遮罩与微调导出**：一键模糊原文进行盲听训练；支持在网页内直接微调句首/句尾时间、拆分或合并句子，支持导出 `.lrc` / `.srt` / `.json`。

## 运行环境要求

- macOS（Apple Silicon 或 Intel；音频解码优先调用系统内置 `afconvert`，并自带 PyAV 回退）
- Python 3.9 – 3.13（推荐 Python 3.11+；已兼容系统自带 Python 3.9）

## 快速启动

```bash
git clone <你的仓库地址>
cd listen-sync
chmod +x start.sh 启动ListenSync.command
./start.sh
```

或者直接在 Finder 中双击 `启动ListenSync.command`。首次运行会自动创建 `.venv` 并安装依赖，服务就绪后自动在浏览器打开 `http://127.0.0.1:8765`。

> **提示**：首次对齐听力时会自动下载 Whisper `base` 模型（约 140 MB）到 `models/` 目录；若直连 HuggingFace 较慢，程序会自动回退至 `hf-mirror.com`。

## 快捷键

- `Space`：播放 / 暂停（在「单句停顿」模式下播完自动停顿时，按 `Space` 自动听下一句）
- `←` / `→`：上一句 / 下一句
- `R`：重听当前句
- `1` / `2` / `3`：切换「连续歌词」/「单句停顿」/「单句循环」
- `B`：开启/关闭盲听遮罩
